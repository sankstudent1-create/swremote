Helping someone without an account? Ask for their ID + PIN.

How it works

  1. On the PC: open SWRemote-Agent.exe — a window shows its ID and PIN.
  2. Claim it: tap Add device and enter the link code from the PC app — it appears here, privately.
  3. Connect: tap a device — no PIN needed, you're signed in on both sides.

Which one do I need?

  1. Your own computer → Setup.exe: installs once, stays updated, starts with Windows if you want.
  2. Helping someone else → send them Agent.exe: they run it, give you the ID + PIN, done.
